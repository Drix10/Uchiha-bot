# Uchiha Bot (Original): My First Public Discord Bot

The original **Uchiha Bot**, a multipurpose **discord.js v12** bot and the first public Discord bot I built: moderation, fun, games, giveaways, info and utility commands. It is kept here as an archive; the newer version lives at **[Drix10/Uchiha](https://github.com/Drix10/Uchiha)**.

## Highlights

- Moderation, fun and utility commands
- Music playback with ytdl-core
- Weather and Urban Dictionary lookups
- Express keep-alive server for free hosting on Glitch

## Run it

```bash
git clone https://github.com/Drix10/Uchiha-bot.git
cd Uchiha-bot
npm install
# set your token in config.js
node index.js
```

> Built for discord.js v12, so it needs updates to run on current Discord APIs.
